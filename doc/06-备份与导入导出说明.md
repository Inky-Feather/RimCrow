# 备份与导入导出说明

这份文档说明 RimCrow 里的加载顺序备份、外部列表导入导出、分享码、软件数据包和模组实体包。它适合需要恢复列表、迁移配置或分享整合包的用户。

先区分两类东西：

- 加载顺序：当前环境启用了哪些 Mod，以及它们的顺序。
- 软件数据或模组文件：RimCrow 设置、规则、环境数据，或者真实 Mod 文件。

## 加载顺序备份

加载顺序备份用于保存当前环境的启用列表和顺序。它不等于完整备份 Mod 文件。

常见用途：

- 大改排序前留一份回退点。
- 自动排序前后对比。
- 测试不同 Mod 组合。
- 从旧环境恢复某个顺序。

备份页会显示几类记录：

- 临时导入：刚从外部文件或分享码导入，还没有正式保存为备份。
- 最新备份：最近一次相关备份。
- 今日动态：今天产生的备份。
- 历史归档：较早的备份。
- 手动备份：用户另存或整理过的备份。

## 导入加载顺序

导入用于读取外部列表，并放到对比视图里。导入后不要急着覆盖当前列表，先看差异和缺失项。

支持的常见格式包括：

- `ModsConfig.xml`
- `ModList.xml`
- `.rml`
- RimPy XML
- RimSort JSON
- 文本列表
- Workshop ID 列表
- RimWorld 存档 `.rws`
- RimCrow 分享码

导入后可能出现：

- 当前环境已有的 Mod。
- 当前环境缺失的 Mod。
- 只有包名、暂时找不到来源的项。
- 带工坊 ID，可以尝试补订阅或补下载的项。

## 导出加载顺序

导出用于把当前启用列表保存成外部文件，方便分享或迁移。

常见格式：

| 格式 | 适合场景 |
| --- | --- |
| `ModsConfig.xml` | 给 RimWorld 或其它工具读取，仅表达包名顺序 |
| `ModList.xml` | 分享列表和工坊 ID 信息 |
| `RML` | 更接近 RimWorld 原生列表格式，适合兼容部分外部流程 |
| 分享码 | 快速复制给别人导入 |

如果你要让别人尽量补齐 Mod，优先选择包含工坊 ID 或来源信息的格式。

## 加载备份前要确认什么

加载备份会把当前启用列表恢复到备份状态。当前未保存的更改会丢失。

加载前建议检查：

- 这个备份属于哪个环境。
- 是否有缺失项。
- 是否和当前游戏版本匹配。
- 是否会覆盖你刚手动调整但还没保存的顺序。

如果只是想看差异，先选中备份查看，不要马上加载。

## 跨环境查看备份

备份页可以切换其它环境的备份。这样你可以查看旧环境或测试环境的加载顺序。

注意：

- 查看不等于切换当前环境。
- 加载到当前环境前要确认缺失项和路径差异。
- 不同环境可能使用不同游戏版本和用户数据目录。

## 分享码

分享码适合快速把当前启用序列发给别人。

适合：

- 临时分享列表。
- 让别人导入后检查缺失项。
- 不想传文件时使用。

注意：

- 分享码不包含真实 Mod 文件。
- 对方仍需要拥有对应 Mod 来源。
- 分享码里的来源信息越完整，补齐越方便。

## 推荐清单导出

推荐清单导出适合把整合包整理成更适合阅读和传播的说明材料。

常见格式：

- 文本：简单复制和粘贴。
- Markdown：适合论坛、仓库和文档。
- DOCX / PDF：适合正式分享。
- 图片：适合社群传播。
- 动图：适合展示加载顺序或列表效果。

推荐清单偏“展示和说明”，不等于完整数据备份。

## 软件数据导入导出

软件数据包用于迁移 RimCrow 自己的数据。

常见内容：

- 设置。
- 规则。
- 提示词。
- 环境数据。
- 其它管理器配置。

适合：

- 换电脑。
- 重装软件。
- 备份自己的配置。
- 在多台机器间同步管理器设置。

导入前建议先保留当前数据备份，避免覆盖后难以回退。

## 模组实体包导入导出

模组实体包会处理真实 Mod 文件，比加载顺序导出更重。

适合：

- 打包一批本地 Mod 给另一台机器。
- 迁移没有稳定下载来源的 Mod。
- 保存某个整合包当前文件状态。

导出前要注意：

- 文件体积可能很大。
- 工坊 Mod 可能由 Steam 管理，直接复制后更新口径会变化。
- 需要确认磁盘空间。
- 导入时要处理路径、冲突和覆盖风险。

如果只是分享列表，不要用实体包；用推荐清单、分享码或加载顺序导出更轻。

## 推荐流程

### 大改排序前

1. 先保存当前列表。
2. 保留一份手动备份。
3. 再自动排序或批量调整。
4. 对比差异。
5. 确认无问题后保存。

### 导入别人列表

1. 导入文件或分享码。
2. 查看差异。
3. 检查缺失项。
4. 补订阅或补下载。
5. 再决定是否加载到当前环境。
6. 保存。

### 换电脑

1. 导出软件数据包。
2. 需要真实 Mod 文件时，再导出模组实体包。
3. 新电脑先配置游戏路径和用户数据目录。
4. 导入数据。
5. 扫描。
6. 检查缺失和路径问题。

## 常见问题

### 备份会保存 Mod 文件吗？

普通加载顺序备份不会保存真实 Mod 文件。它主要保存启用顺序和相关列表信息。

### 导入后为什么有缺失项？

导入文件里有某些包名，但当前环境没有找到对应 Mod 文件。可以补订阅、补下载，或手动移除缺失项。

### `ModsConfig.xml` 和推荐清单有什么区别？

`ModsConfig.xml` 更偏游戏读取；推荐清单更偏给人看和分享。

### 软件数据包和模组整合包怎么选？

只迁移 RimCrow 设置、规则和环境数据，用软件数据包。要带真实 Mod 文件，用模组整合包。

## 注意事项

- 加载备份会覆盖当前启用列表，操作前先确认。
- 导入外部列表后先看差异，不要立刻覆盖。
- 分享码和列表文件不等于 Mod 文件。
- 导出实体包前检查磁盘空间和来源权限。
- 数据异常时先保留现有目录和备份，不要直接删除数据库。
