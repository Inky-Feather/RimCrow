# 快速上手

这份文档适合第一次使用 RimCrow 的玩家。目标很简单：让软件识别你的游戏和 Mod，整理加载顺序，保存后启动游戏。

如果你只想先跑通流程，按下面四步走：

```text
扫描 -> 自动排序 -> 保存 -> 启动游戏
```

## 第一次打开先做什么

### 1. 确认游戏路径

先确认 RimCrow 找到的是 RimWorld 安装根目录，不是 exe 文件本身，也不是 `Data` 或 `RimWorldWin64_Data`。

Steam 版通常在：

```text
Steam库/steamapps/common/RimWorld
```

用户数据目录应选择 RimWorld 的用户数据根目录，里面通常有：

```text
Config/
Saves/
```

路径、环境、Steam 启动和工坊链接的详细说明见 [环境管理与路径说明](./环境管理与路径说明.md)。

### 2. 扫描模组

路径确认后，先点击“扫描”。扫描会读取当前环境下能看到的本地 Mod、工坊 Mod、管理器模组和相关信息。

普通扫描适合日常使用。发现列表明显不对、刚手动改过文件、或者怀疑缓存没有刷新时，再尝试更彻底的扫描。

### 3. 整理启用列表

主界面通常分成两侧：

- 停用列表：你拥有但当前不加载的 Mod。
- 已启用列表：游戏实际会读取的加载顺序。

常用操作：

- 双击 Mod：在启用和停用之间切换。
- 拖拽 Mod：调整位置或移动到另一侧。
- 批量选择：`Ctrl+左键` 多选、`Shift+左键` 连选、`Ctrl+A` 全选、从序号长按鼠标划动扩选。
- 右键菜单：执行更多操作，例如打开目录、编辑信息、处理来源。

红色或黄色提示一般表示依赖、顺序、兼容性或缺失问题。启动前建议先处理红色错误。

模组列表的详细说明见 [模组列表与加载顺序说明](模组列表与加载顺序说明.md)

### 4. 自动排序

点击“自动排序”后，RimCrow 会根据 Mod 原生依赖、社区规则、用户规则、动态规则等信息重新整理启用列表。

自动排序不是“保证完美”的按钮。它更适合先给出一个合理基础顺序；排序后仍要看问题提示和差异，再决定是否手动微调。

自动排序和规则的详细说明见 [自动排序与规则说明](./自动排序与规则说明.md)。

### 5. 保存加载顺序

拖拽、启停和自动排序后的变化，只有保存后才会真正写入当前环境的加载顺序文件。

保存前建议：

- 看一下是否还有红色错误。
- 确认当前环境是不是你想改的环境。
- 重要列表可以先保留备份。

### 6. 启动游戏

保存后再启动游戏。RimCrow 会按当前环境的设置启动 RimWorld，并在需要时先同步管理器链接。

如果启动前链接同步失败，不会继续启动。先按提示检查路径、权限和 `_Link_...` 链接状态。

## 推荐的日常流程

### 新装一批 Mod 后

1. 扫描。
2. 把需要的 Mod 移到已启用列表。
3. 自动排序。
4. 处理缺失依赖、顺序错误和兼容性提示。
5. 保存。
6. 启动游戏测试。

### 更新或删除 Mod 后

1. 扫描。
2. 查看缺失、已删除、重复或共存提示。
3. 必要时重新自动排序。
4. 保存。
5. 启动游戏。

### 导入别人分享的列表后

1. 在备份页导入文件或分享码。
2. 先看差异和缺失项。
3. 使用补订阅、补下载或手动处理缺失项。
4. 确认列表合理后再加载到当前环境。
5. 保存并启动。

备份和导入导出说明见 [备份与导入导出说明](./备份与导入导出说明.md)。

## 常见问题

### 扫描后没有看到工坊 Mod

先检查创意工坊目录是否填写正确，路径一般是：

```text
steamapps/workshop/content/294100
```

如果你开启了 Steam 启动，工坊内容主要由 Steam 处理；如果你不通过 Steam 启动但想读取已有工坊目录，需要开启“使用创意工坊 Mod”。

### 排序后还存在警告

这很常见。自动排序只能根据已有规则处理问题，没有规则或信息不足时仍需要用户确认。

红色错误优先处理。黄色警告可以结合 Mod 说明、规则来源和实际使用情况判断。

### 保存后游戏里没变化

先确认：

- 保存的是当前环境。
- 游戏没有同时开着旧实例。
- RimWorld 读取的用户数据目录和当前环境一致。
- 没有手动给启动参数添加错误的 `-savedatafolder`。

### 不确定下一步点什么

按主流程走：扫描、自动排序、保存、启动。遇到问题时，先看列表顶部的问题汇总，再看具体 Mod 的提示。

## 注意事项

- 第一次整理大型列表时，不建议一次处理太多不熟悉的高级功能。
- 重要列表建议保存前保留备份。
- 不要直接删除数据库或用户数据目录来“修复问题”。
- 分享日志、路径或导出包前，注意里面可能包含本地路径和 Mod 清单。
